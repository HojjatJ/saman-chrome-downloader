نصب افزونه (بدون فروشگاه گوگل)
1. فایل zip را در یک پوشه ثابت extract کنید (بعد از نصب پوشه را پاک یا جابجا نکنید).
2. در Chrome یا Edge آدرس chrome://extensions را باز کنید.
3. «Developer mode» را روشن کنید.
4. روی «Load unpacked» بزنید و همان پوشه را انتخاب کنید.
5. آیکون افزونه را به نوار ابزار سنجاق کنید.
